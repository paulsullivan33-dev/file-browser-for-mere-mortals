$ filebrowser cmds --help
Command runner management utility.

Usage:
  filebrowser cmds [command]

Available Commands:
  add         Add a command to run on a specific event
  ls          List all commands for each event
  rm          Removes a command from an event hooker

Flags:
  -h, --help   help for cmds

Global Flags:
  -c, --config string     config file path
  -d, --database string   database path (default "./filebrowser.db")

Use "filebrowser cmds [command] --help" for more information about a command.
